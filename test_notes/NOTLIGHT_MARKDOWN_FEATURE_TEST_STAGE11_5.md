# H1 — заголовок первого уровня

Эта заметка предназначена для ручной проверки **всего Markdown-dialect, который заявлен встроенным Notes renderer NotLight Stage 11.5**. Проверь её в режиме «Чтение», в Markdown-редакторе, как лёгкую заметку на доске и — при необходимости — с включённым «Полным рендером обычных заметок» в Custom Performance.

## H2 — базовая inline-разметка

Обычный текст. **Жирный через звёздочки**, __жирный через подчёркивания__, *курсив через звёздочку*, _курсив через подчёркивание_, ~~зачёркнутый текст~~, ==выделенный текст== и `inline_code()`.

Тройные маркеры: ***одновременно жирный и курсивный*** и ___тоже одновременно жирный и курсивный___.

Вложенные комбинации: **жирный и *курсив внутри***, *курсив и **жирный внутри***, ~~зачёркнутый с **жирным** и *курсивом*~~, ==подсветка с `кодом` и **жирным**==.

Экранирование должно оставлять символы литеральными: \*не курсив\*, \_тоже не курсив\_, \`не inline code\`, \~\~не зачёркнуто\~\~, \[\[не wiki-link\]\].

## Цитаты и callouts

> Обычная цитата.
> Вторая строка той же цитаты.

> [!NOTE] Пользовательский заголовок NOTE
> Это обычный нефолдабельный callout.
> Вторая строка callout.

> [!TIP]
> Callout без пользовательского заголовка использует тип как заголовок.

> [!WARNING]+ Раскрываемый callout — стартует открытым
> Эта строка должна скрываться и возвращаться по кнопке fold.
> **Inline Markdown** внутри тела должен продолжать работать.

> [!NOTE]- Свёрнутый callout — стартует закрытым
> При первом открытии заметки эта строка должна быть скрыта.
> После раскрытия она должна стать видимой без изменения canonical Markdown.

## Fenced code — backticks

```cpp
#include <iostream>

int main() {
    std::cout << "NotLight code block" << std::endl;
    return 0;
}
```

У блока должна быть SVG-кнопка копирования. В clipboard должно попасть только содержимое блока — без fences и без `cpp`.

## Fenced code — tildes

~~~gdscript
func typed_example(value: int) -> String:
    var result: String = "value=%d" % value
    return result
~~~

Этот вариант должен распознаваться тем же fenced-code pipeline.

## Block LaTeX — последовательное преобразование в одном блоке

Следующий блок намеренно содержит несколько непустых строк без собственного LaTeX environment. Presentation-layer должен объединить их в `aligned`, **не изменяя canonical Markdown**:

$$
f(x) = x^3 - 2x
f'(x) = 3x^2 - 2
f'(2) = 10
$$

## Block LaTeX — автор сам управляет environment

Если environment уже указан, Notes не должен оборачивать его повторно:

$$
\begin{aligned}
a^2 + b^2 &= c^2 \\
a^2 &= c^2 - b^2 \\
a &= \sqrt{c^2-b^2}
\end{aligned}
$$

Формулы должны выглядеть как часть документа: без плашки «Готово», без ненужного full-width контейнера. Если Formula backend недоступен, должен деградировать только presentation; canonical LaTeX сохраняется.

## Точный переход из «Чтение» в Markdown

Дважды кликни **примерно в середину этого предложения**, например прямо по слову `середину`. NotLight должен перейти в Markdown и поставить caret возле выбранного символа, а не просто в начало всего блока.

Повтори тест на слове **жирный** в этом абзаце и на *курсивном* фрагменте — inline delimiters не должны сдвигать caret на случайную позицию.

## Большой абзац и прокрутка

NotLight должен переносить длинный текст внутри доступной ширины без выхода за панель. Этот абзац намеренно длиннее типичной строки: он проверяет перенос, высоту блока, правый scrollbar Reading view и то, что inline-разметка вроде **важного фрагмента**, *акцента*, ***сильного акцента***, ==подсветки== и `small_code()` не ломает геометрию строки при узком окне. Scrollbar должен использовать визуальный стиль Notes/NotLight, а не системный серый skin.

## Контроль границ текущей реализации — ожидается литеральный текст

Следующие конструкции **на Stage 11.5 не заявлены как полноценно поддерживаемые**. Они нужны как regression-control: Notes не должен повреждать canonical Markdown и не должен изображать поддержку там, где её пока нет.

Inline LaTeX: $x^2 + y^2 = z^2$

<div>Произвольный HTML должен оставаться обычным содержимым, а не исполняться как HTML.</div>

## Финальная проверка

Если этот файл импортирован без ошибок, проверь:

- front matter не отображается как обычный основной текст;
- H1–H6 различаются;
- bold, italic, triple bold+italic и вложенные комбинации визуально различимы;
- escaping оставляет маркеры литеральными;
- safe HTTP/HTTPS/mailto links кликабельны;
- Wiki-link/backlink обновляется при создании и rename целевой заметки;
- три horizontal rules выглядят как разделители;
- lists/tasks отображаются структурно, checkbox компактный и редактирует source;
- quote и callout визуально различимы;
- `[!TYPE]+` и `[!TYPE]-` foldable callouts раскрываются/сворачиваются;
- table рендерится таблицей;
- оба fenced-code варианта дают CodeEdit и SVG Copy;
- обычный и последовательный block LaTeX используют Formula pipeline без success-badge;
- double-click по абзацу открывает Markdown около выбранного символа;
- Reading view имеет стилизованную вертикальную прокрутку;
- lightweight board Note показывает структурный retained Markdown;
- rich Notes workspace остаётся интерактивным вариантом с деревом/вкладками/графом.
