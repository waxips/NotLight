Фоновая музыка NotLight
=======================

ЭТОТ README лицензирован как часть исходного кода/документации NotLight по
GPL-3.0-or-later. Это НЕ меняет лицензию самих аудиофайлов.

Треки, которые сейчас разрешено включать в официальный релиз NotLight:
  - Hypnothis.mp3 — "Hypnothis", Kevin MacLeod, CC BY 4.0,
    ISRC USUAN1100634
  - Night_20Cave.mp3 — "Night Cave", Kevin MacLeod, CC BY 4.0,
    ISRC USUAN1100446

Полная атрибуция, прямые страницы источников и текст лицензии находятся в:
  - THIRD_PARTY_NOTICES.md
  - THIRD_PARTY_LICENSES/CC-BY-4.0.txt

Если вы добавляете новый трек в эту папку для официальной сборки, сначала
зафиксируйте его автора, источник, лицензию и требуемую атрибуцию в
THIRD_PARTY_NOTICES.md. Не добавляйте музыку с неизвестным происхождением и не
полагайтесь на то, что удаление исходного MP3 автоматически очищает .godot/:
перед публикацией исходного архива каталог .godot/ должен быть удалён целиком.

Поддерживаемые форматы фона:
  - .ogg
  - .mp3
  - .wav

Путь в проекте: res://assets/audio/background/

В Настройки -> Звук можно включить фоновую музыку, выбрать трек и настроить
громкость. Если выбран режим «Автоматически», NotLight использует первый
доступный трек по имени.

Фоновая музыка автоматически полностью приглушается, пока воспроизводится видео,
аудиоресурс или голосовая заметка, и возвращается после паузы/остановки/окончания.

Эта папка предназначена только для треков, которые автор приложения включает
в официальный Godot-экспорт. Пользовательские аудиофайлы не нужно копировать
сюда: их можно добавить в Resource Library и выбрать как фоновую музыку по
стабильному идентификатору ресурса. Пользовательские файлы при этом не становятся
частью официального дистрибутива NotLight и не покрываются атрибуциями выше.
